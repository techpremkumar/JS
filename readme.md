# JavaScript Learning Repository

A hands-on collection of JavaScript examples, browser demonstrations, and beginner-friendly exercises. The repository follows a fundamentals-first path and progresses toward asynchronous JavaScript, DOM manipulation, browser events, and a small Todo application.

## What you'll learn

| Area | Topics |
|---|---|
| Foundations | Variables, constants, data types, type conversion |
| Operators & control flow | Arithmetic, comparison, logical operators, conditionals, switch, loops |
| Functions | Declarations, expressions, arrow functions, callbacks, parameters, return values |
| Data structures | Strings, arrays, objects, maps, sets, JSON |
| Object-oriented JavaScript | Constructors, classes, inheritance, method overriding |
| Core concepts | Recursion, date and time, error handling |
| Asynchronous JavaScript | Promises, chaining, `async` / `await`, callbacks |
| Browser APIs | DOM selection and updates, event listeners, keyboard events |
| Practice | Small programming exercises and a Todo List application |

## Getting started

### Requirements

- A modern browser (Chrome, Firefox, Edge, or Safari)
- A code editor such as Visual Studio Code
- Node.js for running standalone JavaScript examples from the terminal

### Clone the repository

```bash
git clone https://github.com/techpremkumar/JS.git
cd JS
```

### Run browser examples

Open an HTML file directly in your browser, or use the **Live Server** extension in Visual Studio Code. Start with `index.html`; interactive examples include `dom.html`, `eventlistener.html`, `keyboardeventlistner.html`, and `todo.html`.

### Run JavaScript examples with Node.js

```bash
node variable.js
node function.js
node promise.js
```

Run each file individually. These are independent learning examples, not a single application entry point.

## Suggested learning path

1. Start with variables, data types, and type conversion.
2. Learn operators, conditional statements, and loops.
3. Practice functions, arrays, objects, maps, and sets.
4. Study constructors, classes, inheritance, and recursion.
5. Explore errors and asynchronous JavaScript.
6. Move to browser DOM APIs and events.
7. Finish by reading and extending the Todo List example.

## Learning and contribution guidelines

- Keep each example focused on one concept.
- Prefer meaningful variable and function names.
- Add short comments to explain *why* a step is needed, not every obvious line.
- Include sample output or browser instructions where helpful.
- Keep browser-only APIs (such as `document` and `window`) in browser examples.

Issues and pull requests that improve explanations, correctness, accessibility, or examples are welcome.
