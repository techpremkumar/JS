# Contributing

Thank you for helping improve this JavaScript learning repository.

## Before making changes

1. Fork the repository and create a focused branch.
2. Keep each lesson centered on one concept or a closely related group of concepts.
3. Preserve existing lesson filenames unless a rename is necessary and all references are updated.
4. Use clear names, consistent indentation, and short explanatory comments.

## Validate your changes

For standalone JavaScript files, run the relevant example with Node.js:

```bash
node path/to/example.js
```

For browser examples, open the HTML file in a modern browser and verify that its controls and interactions work.

## Pull request checklist

- [ ] The change has a clear learning purpose.
- [ ] Existing examples and links remain functional.
- [ ] JavaScript examples run without syntax errors.
- [ ] Browser examples have valid HTML and usable controls.
- [ ] Comments and instructions are accurate.
- [ ] No credentials, tokens, or personal secrets are included.

Please describe what changed and how you tested it in your pull request.
